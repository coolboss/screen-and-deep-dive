Screener's Excel exports are read here, on your own computer. Nothing is uploaded anywhere.

Find companies to study

Not sure which companies to export? Pick what you are looking for and the app writes a Screener query that matches your goal. Paste it on screener.in, run it, then use the Batch export button to bring the results here. The query runs on Screener, so the count and the names appear there, not here.

Open Screener's query page
    1. Paste and runOn screener.in, open Screens → Create new screen (the link above), paste the query and press Run this query. Check that the count looks sensible: 10 to 60 is a good size. If it is 0, choose Loose or delete one line; if hundreds, choose Strict.
    2. Save it therePress Save this query on Screener and set an alert, so new entrants are emailed to you.
    3. Export the resultsOn the results page press the green Batch export button (the bookmark or the phone script), then Take the companies from this page. Drop the zip in the box below.

    Download many companies at once

    A bookmark that collects the Excel export of every company on your list from screener.in and saves them in one zip file. Set it up once; after that a batch takes a minute or two.

    1. Show your bookmarks barIn Chrome or Edge press Ctrl Shift B (on a Mac, Cmd Shift B).
    2. Drag this button onto the barScreener batch exportDrag it; clicking it here does nothing.
    3. Open screener.in and log inYour own account is used, with its usual export limits.
    4. Click the bookmark and give it your listOn a screen's results page (or a watchlist), press Take the companies from this page: it collects every company, across all pages. Or paste NSE symbols or BSE codes, one per line (for example ICRA, PIDILITIND, 500325). Choose consolidated or standalone and press Start.
    5. Drop the zip file hereIt is saved to your Downloads folder as screener-exports-(date).zip. Drop it on the Add Screener exports box, or use Choose files. On a Mac, Safari may unzip it into a folder instead: then use Choose a folder.
    On a phone or tablet (iPhone, iPad, Android)

    The whole loop works on a phone: export from screener.in, drop the zip here, screen and deep dive. Tested on iPhone.

    iPhone and iPad: Safari blocks bookmarks like this, so use the free Userscripts add-on instead. It puts a green Batch export button on screener.in. Set it up once:

    1. Install UserscriptsGet “Userscripts” (by Justin Wasack) from the App Store. Open it once; the default folder is fine.
    2. Turn it onSettings → Apps → Safari → Extensions → Userscripts: switch it on and set it to Allow.
    3. Install the scriptOpen this script link in Safari. On that page tap the puzzle icon in the address bar, then Userscripts, then Install.
    4. Run it on screener.inOpen screener.in in Safari itself (a Home Screen icon set to open as a web app will not show the button) and log in. Tap the green “Batch export” button, give it your list and tap Start. Keep the phone unlocked until it finishes, then tap Download.
    5. Bring the zip hereTap “Choose files”, then “Choose Files”, Browse, Downloads, and pick the zip. Do not open the zip in the Files app first: that unzips it into a folder (if it has, open the folder, tap Select, select all and tap Open).

    Android, the easy way (Firefox): install Firefox, then the Tampermonkey add-on from its Add-ons menu. Open the same script link in Firefox and tap Install. Log in to screener.in in Firefox and the green Batch export button appears, as on the iPhone. The zip lands in Downloads; pick it with “Choose files” here.

    Android (Chrome), without an add-on: copy the bookmark code, bookmark any page, edit that bookmark and paste the code as its address. On screener.in, type the bookmark's name in the address bar and tap it in the suggestions.

    If it does not work
    • "Not logged in": log in to screener.in in the same browser, then click the bookmark again.
    • "Too many requests" or a limit message: wait a while, raise the gap between companies to 6 to 10 seconds, and use "Put the failed ones back in the box".
    • A company "not found": check its symbol on its Screener page; the address shows it, for example screener.in/company/ICRA.
    • The button will not drag: on a computer use Chrome or Edge; on a phone or tablet follow the steps under On a phone or tablet above.

    Optional: add your holdings

    Skip this if you only want to research companies; everything else works without it. If you add the shares you own (one file per account: yours, Sangeeta's, HDFC Securities), the Action plan uses your real buy price and quantity, and the Screen page tells you what to do with each holding. Kept only in this browser; remove it any time.

    • No Kite login needed. Download the holdings file from Zerodha (two clicks) and choose it here. This works for every account, including Sangeeta's and HDFC Securities.
    • One file per account. Give each one a name, for example "Rajesh (Zerodha)". Importing again under the same name replaces the old file.
    • Private. The file is read on this computer and kept only in this browser.
    How to download your holdings
    • Zerodha, quickest: log in at kite.zerodha.com, open Holdings and press the download icon above the list (a CSV file).
    • Zerodha, with the 12-month split: console.zerodha.com, Portfolio, Holdings, then Download (an Excel file). It also says how many shares are held over a year, which sets the tax.
    • Sangeeta's account: log in with her Zerodha user ID (on this computer, or she downloads it and sends you the file), download the same file and import it with the name "Sangeeta (Zerodha)".
    • HDFC Securities: open your equity holdings or portfolio page and use its Download or Export option (Excel or CSV). Import it as "HDFC Securities". If its file lists company names instead of symbols, the app matches the names.
    • Import again whenever you like: the same account name replaces the older file. Mutual funds and ETFs are left out.

    Settings for experts

    Tax rates, earnings options and forensic thresholds. The defaults suit most users.

    Income & tax assumptions
    Dividend tax %
    Listed equity STCG tax %
    Listed equity LTCG tax %
    Default rates are editable and are not fetched live. The selected-horizon lens switches from STCG to LTCG only when the holding period is more than 12 months. Exemptions, surcharge/cess, loss set-offs and transaction costs are not modeled. Tax defaults last reviewed for this build: 2026-10-02.
    In auto mode, the terminal writes adopted growth, terminal growth and exit multiple into the fields. Editing any of those fields switches auto mode off so a deliberate manual assumption is never silently overwritten.
    Calibration note: archetype growth floors/caps, valuation multiples and ceilings are disciplined defaults, not facts. Benchmark several businesses you know well before using the terminal at scale, and use Advanced settings to challenge—not merely confirm—the model.
    Sets the exit P/E used for the fair value and the 5-year return in every engine. Not used where a P/E history means little: commodities, cement, hotels, shipping, airlines, telecom and NAV-based classes.
    TTM affects the current EPS/multiple and return anchor only. Historical growth, accounting quality and forensic trends remain annual, preventing quarterly data from contaminating the long-run record.
    Uses median Δ net block + Δ CWIP + depreciation from recent annual periods when at least three usable observations exist; otherwise falls back to the depreciation proxy.
    Investments counted as cash %
    Blank = Auto: a share of the Investments line is counted as cash by business class (80% for IT, rating agencies and exchanges; about half for pharma and consumer; 40% for manufacturing; none for lenders, insurers and holding companies, whose investments are the business). Type a number to override after checking what the investments are.
